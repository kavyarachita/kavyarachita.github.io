# Kavya Annapareddy Portfolio

A personal portfolio site built with React and TypeScript to showcase experience, projects, skills, and hobbies.

## Highlights
- Responsive single-page portfolio
- Light and dark mode
- Password-protected access for recruiter viewing
- Downloadable resume
- Project and contact links

## Tech Stack
- React
- TypeScript
- Vite
- SCSS

## Run locally
```bash
npm install
npm run dev
```

## Notes
This site is designed to share my work and background in a polished, approachable format while keeping recruiter access controlled through a password-protected view.
